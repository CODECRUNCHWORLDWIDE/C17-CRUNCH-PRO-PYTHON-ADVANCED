# Week 1 — Exercises

Short drills. Each takes 20–40 minutes. Do them in order.

1. **[Exercise 1 — Tokenize and AST](exercise-01-tokenize-and-ast.py)** — produce tokens and AST for five expressions. (~30 min)
2. **[Exercise 2 — Disassemble](exercise-02-disassemble.py)** — disassemble five different code shapes and annotate each opcode. (~35 min)
3. **[Exercise 3 — Read a `.pyc` file](exercise-03-pyc-reader.py)** — parse a `.pyc` file's header and unmarshal its code object. (~30 min)

## Workflow

- Type, don't paste.
- Run, observe, explain (out loud or in a comment) before moving on.
- Don't peek at the hint blocks until 15 minutes of trying.

## Self-grading

After each exercise, ask yourself: "Could I explain this to a junior engineer in 3 minutes?" If yes, move on. If no, re-read the lecture material that covered it.
