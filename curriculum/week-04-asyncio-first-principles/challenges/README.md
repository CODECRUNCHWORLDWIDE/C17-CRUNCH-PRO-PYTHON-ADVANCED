# Week 4 — Challenges

One stretch challenge this week. The mini-project itself is substantial; the challenge is to **rebuild a runnable subset of asyncio from scratch in one timed sitting** before you start the multi-day project.

1. **[Build an asyncio clone in 4 hours](challenge-01-asyncio-clone.md)** — `Future`, `Task`, `sleep`, `gather`, `run` against your own event loop. ≤300 lines, in ≤240 minutes, no reference to the mini-project solution. Builds the muscle for the mini-project. (~4 hours)

If you finish early, port the [Exercise 3 TaskGroup demo](../exercises/exercise-03-taskgroup-fan-out.py) onto your clone — i.e., add a `TaskGroup` analogue. This is the optional second tier of the mini-project and the first tier of Week 5.
