# Week 3 — Challenges

One stretch challenge this week. The mini-project itself is substantial; the challenge is to **write it from scratch in one timed sitting** before you start the multi-day project.

1. **[Write a 100-line tracer in one sitting](./challenge-01-write-a-100-line-tracer.md)** — build a working bytecode tracer in ≤100 lines, in ≤90 minutes, with no reference to the exercise solution. Builds the muscle for the mini-project. (~90 min)

If you finish early, attempt the same challenge using `sys.settrace` instead of `sys.monitoring` — and write up the differences in the resulting trace fidelity.
